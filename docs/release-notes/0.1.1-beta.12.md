# 0.1.1-beta.12 — Tenant guidance and AI-enriched alert flows

AI Ops uses the same server-side client identity as the client directory,
including hostname, separate friendly name, OS, architecture, IP addresses,
tags, connection status, version and last-known observation times. Investigation
requests include the tenant name and immutable scope IDs. Operators can inspect
the guidance revisions and recorded context used for a turn.

## Tenant prompts

**AI Ops → Prompts** provides tenant-scoped guidance with Monaco editing,
optimistic concurrency, immutable revisions and an optional tenant default.
New investigation sessions snapshot the current default and their ordered
optional selections. Later prompt edits do not alter existing sessions.
Published flows pin their optional guidance revisions; archiving retains
referenced history. Prompt text does not grant tools, credentials or approval.
The shared composer validates the actual serialized 28,000-byte chat request
and reports oversized input without truncating required guidance or questions.

## Completion-dependent flows

An incident flow can now use **Alert raised → Map alert fields → AI: Investigate
alert → RatelDesk: Create incident**. AI queue admission leaves the flow waiting.
Only a committed result for the exact automated investigation turn releases its
continuation. Approval waits, unsuccessful outcomes and delivery uncertainty
remain distinct. AI node settings select a bounded deadline and failure
disposition, including continuing with the original alert and a labelled
unsuccessful AI outcome.

Incident descriptions retain original alert facts and append a labelled AI
investigation section. Persisted checkpoints and the existing receiver receipt
contract preserve the same downstream action key and semantic payload across
restart, duplicate completion and delivery recovery. Existing incident-only,
AI-only and independent action-group flows remain supported. Editing, preview
and dry run remain inert.

## Integration and search

Netclaw management is a tab under **Integration**. Legacy `/ai/integration`
bookmarks redirect while retaining their tenant. The workspace status shows a
fresh observed SignalR connection separately from historical verification;
hover and keyboard focus reveal only available authorized diagnostics.

App-bar search adds monitoring alerts, flows and AI investigations to its six
existing groups. Results are permission-filtered before snippets and counts
are returned, and links select the exact entity in its authorized tenant.

## Upgrade and acceptance

Apply the normal forward PostgreSQL migration and preserve the deployment's
Data Protection keys. The generic hosted release workflows produce the client
archives, checksums, SBOMs, digest-pinned Compose bundle, publication record and
all five public images. Successful distribution verification is separate from
the owner's deployed Netclaw, LLM, tool-policy and OTEL acceptance. This release
does not roll out clients or deploy the operator's production stack.
