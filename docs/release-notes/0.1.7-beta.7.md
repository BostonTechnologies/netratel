# NetRatel 0.1.7-beta.7

- Configured OIDC administrators can approve saved-account execution for existing paired jobs. NetRatel checks the retained pairing and mapping owners independently. [#859](https://github.com/BostonTechnologies/netratel/issues/859)
- Paired execution readiness distinguishes missing, revoked and changed approvals. The approval dialog shows the effective targets and profiles. [#859](https://github.com/BostonTechnologies/netratel/issues/859)

Upgrade NetRatel first, then RatelDesk 0.1.4-beta.12. Review the existing mapping and approve the job under **System connections → Paired Run as**. Refresh readiness in RatelDesk before retrying a rejected task. The installed Windows on-behalf Add and Remove journey remains pending owner acceptance. [Pairing guide](../integrations/rateldesk-pairing.md#approve-a-saved-execution-account-for-a-job)
