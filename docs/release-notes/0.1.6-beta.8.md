# NetRatel 0.1.6-beta.8

- The Web viewer SBOM and notices now track the exact shipped JSZip 3.10.1, docx-preview 0.3.3 and PDF.js 6.5.438 files and the modules embedded in JSZip. The audited npm lockfile replaces the copied upstream build manifests. The AppHost retains Aspire 13.6.5 for Hosting, AppHost and its Dashboard. [#804](https://github.com/BostonTechnologies/netratel/issues/804)
- The self-contained `linux-musl-x64` client archive supports manual enrollment and operation on Alpine x86_64. Install the listed system libraries and bash before running the archive and native PTY check. OpenRC installation and service-managed updates remain follow-up work. [Alpine client instructions](../client/CLIENT.md#alpine-x86-64-client-archive) · [#776](https://github.com/BostonTechnologies/netratel/issues/776)

Upgrade using the matching digest-pinned Compose bundle to pick up the Web distribution changes. Developers running Aspire from an older checkout should update their checkout, restore and restart the AppHost to load the patched Dashboard. [Install the release bundle](../../release/INSTALL.md)
