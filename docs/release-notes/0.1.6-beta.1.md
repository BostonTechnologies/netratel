# NetRatel 0.1.6-beta.1

- Chat and AI Ops keep scheduled reminder references with the original conversation. NetClaw 0.28.2 shows **Scheduled report delivery unconfirmed** when exact delivery evidence is unavailable. [#757](https://github.com/BostonTechnologies/netratel/issues/757)
- Configured OIDC browser administrators can open MCP Policies through their application authority. Admin → Access can select OIDC principals by issuer and subject for role assignment. The broader role-mapping cutover remains open. [#478](https://github.com/BostonTechnologies/netratel/issues/478)
- Incident-origin MCP job-run denials direct operators to the authorized incident's retained Automation report. Job-run ownership still governs direct reads. [#646](https://github.com/BostonTechnologies/netratel/issues/646)

This beta includes the previous fixes for multiline drafts, prepared aggregate investigations, and missing-path classification with an updated Client. The Slopwatch 0.5.0 gate continues to run on PRs and releases. [#756](https://github.com/BostonTechnologies/netratel/issues/756), [#759](https://github.com/BostonTechnologies/netratel/issues/759), [#755](https://github.com/BostonTechnologies/netratel/issues/755), [#761](https://github.com/BostonTechnologies/netratel/issues/761)

Keep API and Web at the same version and use the release's digest-pinned Compose bundle for a disposable upgrade test. Native exact-result replay, scheduled-report delivery on 0.28.2, and the long model-phase failure remain open.
