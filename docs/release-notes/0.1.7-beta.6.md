# NetRatel 0.1.7-beta.6

- Configured OIDC administrators can review and approve saved-account execution for existing paired jobs. The pairing and mapping retain their independent authority checks. [#859](https://github.com/BostonTechnologies/netratel/issues/859)
- Paired execution readiness and admission diagnostics explain when approval is missing, revoked or stale. The authorised review shows the effective target and profile. [#859](https://github.com/BostonTechnologies/netratel/issues/859)

Upgrade NetRatel first, then RatelDesk 0.1.4-beta.12. Review the existing mapping and approve the effective job scope under **System connections → Paired Run as**. Refresh readiness in RatelDesk before retrying a rejected task. The installed Windows on-behalf Add and Remove journey remains pending owner acceptance.
