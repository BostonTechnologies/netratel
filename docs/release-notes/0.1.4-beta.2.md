# NetRatel 0.1.4-beta.2

Agent Installers & Updates now has three tabs: GitHub releases, Activity and Suspended. The release catalogue includes remote and retained local versions, with compact import, approval, download and installer-script actions. Expand a version to manage its runtime assets, source checks and local disk cleanup.

Local cleanup previews identify enabled runtimes, imports, transfers, installer links, tenant pins and update attempts. Review a single version or up to 100 selected versions across pages. Explicit all-runtime disabling precedes eligible purges; each version reports its own completion or retryable failure. Decommissioned clients' abandoned authority can be retired with an audit reason and acknowledgement that the physical outcome remains unknown. Admission/result evidence is retained and late authority is fenced.

Tenant deletion revokes enrollment and service credentials and archives prompt data transactionally. A retained tenant identity keeps audit/history references intact; active clients and named connections require their supported decommission/disconnect steps. Unexpected failure notifications use an independent database context and the UI displays a safe correlation reference.

The migration is additive apart from making tenant-name uniqueness apply to active tenants. A newly created tenant with a reused name receives a new identity and inherits no old authority. Use a backup before applying a release migration, as described in the deployment guide.

Distribution integrity is verified by the generic hosted release pipeline. Functional acceptance on an owner-operated deployment remains separate from source regressions and publication checks.
