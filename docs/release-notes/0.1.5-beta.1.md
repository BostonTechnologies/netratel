# NetRatel 0.1.5-beta.1

This prerelease corrects Explorer navigation, preview recovery and presentation on top of stable 0.1.4.

- Populated folders selected in the tree update Files when their asynchronous listing completes, without manual Refresh. Loading, empty and unavailable states are distinct; stale directory completions retain no authority over the current location. Folder/file creation, upload and rename/move visibility remain explicit regression cases. ([#688](https://github.com/BostonTechnologies/netratel/issues/688))
- Rejected malformed, unsupported and over-budget previews show a local warning and retain permitted download/navigation. Failed acquisitions are released; inline/fullscreen consumers remain independent. This does not classify the separate, unreproduced HTTP 400 report. ([#689](https://github.com/BostonTechnologies/netratel/issues/689))
- Tiles uses bounded rendering for the loaded directory instead of the pinned list virtualizer's unstable wrapping-grid geometry. Details retains virtualization and the 4,096-entry limit is unchanged. ([#690](https://github.com/BostonTechnologies/netratel/issues/690))
- PDF page/zoom buttons are grouped and styled, expose readable status and keyboard focus, and disable at boundaries and during loading/failure. Local PDF.js rendering and authenticated ranges remain in place. ([#691](https://github.com/BostonTechnologies/netratel/issues/691))
- The existing card folder icon is the sole Basic/Full Explorer menu activator. It always offers both choices; explicit preference persistence and disk-row behavior remain available. ([#693](https://github.com/BostonTechnologies/netratel/issues/693))

Use the [Explorer guide and disposable retest checklist](../operations/remote-file-explorer.md). Selected browser tests exercise the actual restored Blazor/MudEx components with synthetic transport responses. The optional `filesystem` suite executes existing native gateway/filesystem tests on GitHub-hosted Windows and Linux with disposable roots. These are separate from release build/distribution integrity and owner deployment acceptance.

Download this beta's matching archives, digest-pinned Compose bundle, `SHA256SUMS` and `publication.json`. Stable 0.1.4 remains the stable release. Owner environment acceptance is pending; no deployment is performed by this release task.
