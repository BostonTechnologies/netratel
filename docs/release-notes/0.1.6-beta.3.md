# NetRatel 0.1.6-beta.3

- **Monitoring → Metrics** adds retained CPU, memory, disk, per-interface network RX/TX and watched-service history. Compare observed throughput and selected-period Received and Sent bytes. Open the surrounding time from a device alert. [#765](https://github.com/BostonTechnologies/netratel/issues/765), [#766](https://github.com/BostonTechnologies/netratel/issues/766), [#769](https://github.com/BostonTechnologies/netratel/issues/769)
- **Rules & groups** adds tenant collection, service watches and retention settings. Defaults are 14 days at one minute, 90 days at five minutes and 365 days at one hour. [#767](https://github.com/BostonTechnologies/netratel/issues/767)
- REST, CLI, stdio MCP and HTTP MCP expose a shared catalogue, whole-range summaries and collection status. [#768](https://github.com/BostonTechnologies/netratel/issues/768)

Apply the PostgreSQL migration and deploy matching API and Web versions. Upgrade clients for measured network throughput and volume and corrected Windows CPU. Older clients retain qualified observations. Verify interface rates, byte volume, watched-service states, retention and restart persistence in a disposable tenant. [Monitoring upgrade and retest](../operations/MONITORING.md#retest-after-upgrading)
