# NetRatel 0.1.4

NetRatel 0.1.4 brings a more capable automation workspace, richer remote file tools and a clearer path from a monitoring alert to an operator-led investigation. It consolidates the changes shipped across the 0.1.4 betas into one stable release.

## Highlights

- **Flows adds visual authoring and detailed run inspection.** Configure typed triggers, actions, conditions and bindings in the canvas; preview execution paths, inspect recorded playback and follow durable node-level results. Execution-event subscriptions cover jobs, library scripts and requests, with explicit source selection and bounded correlation. Published versions pin their inputs and authority. Searchable flow management, version/run history, lifecycle controls and reviewed deletion make ongoing maintenance easier. Monitoring links connect an alert to its exact flow run, incident receipt and immutable version. ([#615](https://github.com/BostonTechnologies/netratel/pull/615), [#636](https://github.com/BostonTechnologies/netratel/pull/636), [#664](https://github.com/BostonTechnologies/netratel/pull/664))
- **Basic and Full Explorer offer a choice of file workspaces.** Full Explorer adds a folder tree, sortable details/tiles, docked Preview/Details panels, fullscreen viewers and popout/rejoin controls. Authorized file creation, uploads, rename/move and recursive deletion retain capability checks, explicit confirmations and version checks. Local viewers handle supported documents and archives with bounded parsing. Basic remains available, and the selected Explorer preference is remembered. ([#677](https://github.com/BostonTechnologies/netratel/pull/677))
- **Monitoring gains a focused management workspace.** Muted Rules / Groups / Bypasses subtabs provide searchable, sortable tables with genuine 20/50/100 pagination. Alert/history queries gain complete-result filters and paging. Disk policies distinguish eligible resources, expose cached previews and pin readable incident context. Alert rows expose six existing client-tool dialogs through a compact outlined menu. A separate AI action creates an investigation in a new tab with the exact device and authorized alert context prepared. The draft remains unsent until the operator reviews it and selects **Start investigation**. ([#659](https://github.com/BostonTechnologies/netratel/pull/659), [#692](https://github.com/BostonTechnologies/netratel/pull/692))
- **AI conversations and operations are easier to follow.** Shared chat controls, copyable Markdown tables, saved answers and protocol-aware recovery improve continuity without blindly resending uncertain turns. Release management unifies catalogue, activity, suspended updates and reviewed local cleanup; Script Library adds revision-aware folder moves. Tenant deletion revokes credentials while retaining audit identity. Diagnostic logging and bounded Docker retention reduce routine log volume while preserving requested command output. ([#469](https://github.com/BostonTechnologies/netratel/pull/469), [#472](https://github.com/BostonTechnologies/netratel/pull/472), [#580](https://github.com/BostonTechnologies/netratel/pull/580), [#655](https://github.com/BostonTechnologies/netratel/pull/655))
