# NetRatel 0.1.6-beta.2

- **Monitoring → Metrics** adds retained CPU, memory, disk, network RX/TX and watched-service history. View one computer at a time, compare observed rates and per-interface received/sent bytes, and open the surrounding time range from a device alert. [#765](https://github.com/BostonTechnologies/netratel/issues/765), [#766](https://github.com/BostonTechnologies/netratel/issues/766), [#769](https://github.com/BostonTechnologies/netratel/issues/769)
- Each tenant can configure collection, service watches and retention in **Rules & groups**. The default horizons are 14 days at one minute, 90 days at five minutes and 365 days at one hour. [#767](https://github.com/BostonTechnologies/netratel/issues/767)
- REST, CLI, stdio MCP and HTTP MCP can query the same catalogue, whole-range summaries and collection status. [#768](https://github.com/BostonTechnologies/netratel/issues/768)
