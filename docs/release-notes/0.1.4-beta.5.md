# NetRatel 0.1.4-beta.5

AI Chat and AI Ops now accept the nullable turn identity emitted on ordinary NetClaw 0.28.2 output. Beta.4 treated `turnNumber: null` as a mismatched numbered event and discarded valid text, streaming deltas and tool activity while accepting the numbered completion. Numeric stale/foreign turns and tenant/session binding checks remain enforced.

Full text and streamed drafts persist without duplicate final replies. A completed turn without an answer now records an explicit missing-output diagnostic and remains unresolved, retaining a healthy receiver for delayed output. Quiet completions are labelled. Recovery checks history without resending operations. Continuation turns can use the previous verified live terminal count for the same session and exact preceding message when attachment supplies no fresh snapshot.

The [investigation and test report](../evidence/netclaw-output-20261103.md) separates the verified source/wire-contract regression from pending deployed functional acceptance. Owner testing against real NetClaw 0.28.2 and the RatelDesk marker comparison remains required; this beta does not claim that production acceptance passed.
