# NetRatel 0.1.5-beta.3

This prerelease corrects group execution semantics and compacts the job workspace from [#716](https://github.com/BostonTechnologies/netratel/issues/716).

- **HA Groups** replace the operator-facing execution-group name. Each new invocation runs the complete ordered workflow on one healthy authorized worker. A durable shared round-robin cursor balances 100 runs 50/50 on two continuously healthy workers, or 25 each on four, and skips offline or expired workers. Explicit nodes and filters retain multi-node execution.
- Worker choice, parent and single-node queue commit together. Preview does not rotate the cursor, duplicate admission keeps its worker, and original-execution reruns retain the admitted choice. Historical schema-1 plans and hashes stay readable. Wire route/tool identifiers remain compatible. Reviewed MCP confirmation, current grants and quotas remain required; crash recovery preserves the chosen worker.
- Bare `.*` selects every authorized node, including nodes without a reported hostname. Bounded explicit regex and the Regex builder preserve literal parameter binding and tenant boundaries.
- The job editor keeps a near-viewport size across all six sections and fills mobile/portrait screens. A reusable **Nodes (count)** chip picker supports search, selection and bounded scrolling through large sets. Run resolves targets automatically; one-off deselection does not modify the saved job and survives edits to job inputs.
- Recent Runs, node/step headers and output tabs are denser, expansion controls sit on the left, and raw GUIDs/digests move to optional technical details. Node output retains its identity, follow state and paging. Live step refresh snapshots collections before awaiting logs, preventing the collection-modified error.

See the [Jobs guide and native acceptance checklist](../operations/JOBS.md), [CLI/MCP operations](../integrations/CLI_AND_MCP.md#execution-groups-and-multi-node-jobs) and [permissions](../operations/rbac.md).

Automated coverage includes real PostgreSQL admission/distribution and reviewed crash recovery with a synthetic native gateway, contract/history compatibility, per-run subset enforcement, selected-node output isolation and actual responsive browser components, including 300-node scrolling. Installed native functional acceptance remains **pending owner testing**; no production deployment is part of this change.

The generic GitHub-hosted workflows produce matching native, CLI and stdio archives, the tool package, SBOMs, five public images, checksums, digest-pinned Compose and `publication.json`. A completed publication record establishes build/distribution integrity separately from native functional acceptance. These notes describe this release; `Directory.Build.props` remains the sole product-version authority.
