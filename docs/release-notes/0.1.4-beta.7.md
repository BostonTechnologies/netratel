# NetRatel 0.1.4-beta.7

Installed software now shows one compact table row per installation in both the
Software Inventory page and the client inventory dialog. Click the row or its
keyboard-accessible chevron to expand or collapse the existing package identity,
installation, client/platform and collection/freshness panels. Collapsed entries
no longer have a separate Package details row.

Each installation expands independently, including the same package installed
on different clients. Client buttons still open the client inventory dialog.
Expansion state resets when switching tenants or clients.

The beta also includes the Requests detail-panel and AI Markdown-table changes
merged since the previous beta. Component regressions cover compact collapsed
rows, row and chevron expansion, preserved detail fields, independent entries
and tenant changes in both inventory scopes. Release publication records report
build and distribution integrity separately from pending owner functional testing.
