# NetRatel 0.1.6-beta.4

- Active alerts open occurrence-specific history through **Client tools → Open metrics**. The trigger matches the adjacent compact actions. [#772](https://github.com/BostonTechnologies/netratel/issues/772)
- **Tenants → Edit Tenant → Metrics** holds collection, retention and service watches. **Save metrics settings** commits the policy separately from tenant profile changes. Scoped monitoring managers can open the Metrics editor through Tenants. [#773](https://github.com/BostonTechnologies/netratel/issues/773)
- The **Clients** telemetry dialog has **Live** and **History** tabs. History uses the same charts, server totals and resource filters as Monitoring, including for offline clients with retained data. [#774](https://github.com/BostonTechnologies/netratel/issues/774)

Deploy the matching image bundle. Check the Active alerts menu, save a test tenant policy and compare the same fixed range and resources in both history views. Repeat the dialog check with an offline client. [Install the release bundle](../../release/INSTALL.md) · [Owner retest steps](../operations/MONITORING.md#retest-the-metrics-controls)
