# NetRatel 0.1.6

- Monitoring and client telemetry show retained CPU, memory, disk, network and watched-service history. Operators can open metrics from an alert and edit collection and retention under the tenant's Metrics settings. [#765](https://github.com/BostonTechnologies/netratel/issues/765) · [#773](https://github.com/BostonTechnologies/netratel/issues/773)
- Fleet brings together client, tenant, installer and software inventory views. Tasks has separate Tasks and History tabs, and Signals brings Monitoring and Flows together. [0.1.6-beta.6](https://github.com/BostonTechnologies/netratel/releases/tag/v0.1.6-beta.6) · [0.1.6-beta.7](https://github.com/BostonTechnologies/netratel/releases/tag/v0.1.6-beta.7)
- HTTP MCP credentials support up to 16 tenant scopes and separate server access. Pairing now checks current permissions before changing an active mapping or revoking its credentials. Sign-in return URLs stay on the application origin. [#777](https://github.com/BostonTechnologies/netratel/issues/777) · [#823](https://github.com/BostonTechnologies/netratel/pull/823) · [#824](https://github.com/BostonTechnologies/netratel/pull/824)
- Full Explorer ships JSZip 3.10.2 and docx-preview 0.4.1 with matching browser asset provenance and licenses. Development AppHost uses Aspire 17.0.0, and the release includes the reviewed .NET dependency updates. [#806](https://github.com/BostonTechnologies/netratel/pull/806) · [#807](https://github.com/BostonTechnologies/netratel/pull/807) · [#810](https://github.com/BostonTechnologies/netratel/pull/810)
- The self-contained Alpine x86_64 client archive supports manual enrollment. Follow the Alpine library and bash prerequisites before running it. [Alpine client guide](../client/CLIENT.md#alpine-x86-64-client-archive) · [#776](https://github.com/BostonTechnologies/netratel/issues/776)

Upgrade using the matching digest-pinned Compose bundle and select the client archive for your operating system and runtime. Owner deployment acceptance is pending. [Install and upgrade guide](../../release/INSTALL.md)
