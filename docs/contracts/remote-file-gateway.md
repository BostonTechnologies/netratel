# Remote file gateway

Browser file operations use the selected tenant and persisted agent through the existing presence-fenced, bidirectional native file channel. The Web host filesystem is never the remote provider. Basic retains its existing V1/V2 entry points and empty-folder deletion contract.

New clients advertise additive `file-roots-v1`, `file-create-v1`, `file-move-entry-v1`, `file-delete-recursive-v1`, `file-read-range-v1` and `file-write-conditional-v1` capabilities. Existing capability names and MCP admission remain unchanged. Browser capabilities intersect native support with effective `file.read`, `file.write` and `file.delete` grants, including instance administrators. Move and replacement also require deletion authority.

`POST filesystem/entries` accepts at most 128 top-level items. Source overlap, roots, descendants and invalid destinations are rejected before dispatch. Each item returns `completed`, `failed`, `cancelled` or `unknown`, a native code and known affected-entry count. Filesystem batches are not atomic. Refresh all affected parents after every outcome. Never replay an uncertain mutation automatically.

New files use create-only native creation. Conditional uploads stage beside the destination, then commit without replacement by default; explicit replacement requires a checked observed-version precondition. Interrupted uploads clean their staging files. Existing Basic writes retain their prior contract. Native exclusive rename supports file and folder moves; it refuses cross-volume moves without copy/delete fallback. POSIX case and significant spaces remain significant. UNC is unsupported. Recursive deletion checks links/reparse points, cancellation and bounds while walking, with limits of 100,000 deleted entries and 128 open directory levels; stopping can leave a partial tree and reports known progress. Basic deletion still requires an empty directory.

`GET`/`HEAD filesystem/content` revalidates the signed-in operator, tenant/agent and observed file version. Single closed, suffix and open-ended byte ranges use native seek and bounded length; responses use 200/206/416 and correct content lengths. Multi-range and unknown units are ignored with a complete 200 response. HEAD ignores Range and describes the complete representation. A weak metadata ETag cannot satisfy If-Range, so that request receives complete content. An observed version uses length and filesystem timestamps: it detects replacement and ordinary in-place changes, but is not a strong content hash or immutable snapshot. Concurrent writes that preserve those metadata are not detectable. A detected change before headers returns 412; after headers it aborts the response, preventing a successful truncated download.

Web content leases are private, reusable and operator-bound, with tenant, agent, exact path, observed version and a 15-minute expiry. Every request still passes API authorization. Each preview consumer receives its own lease or capped stream. Closing one does not revoke another. The registry holds metadata only, with 16 leases per operator and 1,024 total. Responses use `no-store` and `nosniff`. Large downloads retain the existing browser-native HTTP transfer service; the gRPC payload budget remains 12 KiB, with checksums, credits, bounded queues and request/attempt/epoch fences.

Whole-file previews default to the existing 8 MiB cap (configured through `FileBrowser:MaxPreviewBytes`) and check observed bytes as well as stat metadata. No global transport limits are raised. Older clients retain Basic downloads and previews; native seeking and new mutations require their specific capabilities.

Native roots are listed through `GET filesystem/roots`, without enumerating children. Mutation guards also reject mounted volume roots and recursive traversal into nested volumes. Full browser uploads enforce 16 GiB while preserving bounded streaming and explicit conditional replacement. Upload source failures send cancellation to the native staging owner. Closing/expiring/disconnecting a content lease cancels its active HTTP reads. See the [operator guide and exact format matrix](../operations/remote-file-explorer.md).
