# Branding assets

The approved NetRatel web assets are under `src/NetRatel/NetRatel.Web/wwwroot/brand`.
They include the runtime wordmark, small navigation marks, favicon companion,
Apple touch icon, and PWA-sized icons. The responsive Web UI uses the WebP
wordmark rather than a high-resolution master.

`docs/assets/netratel/netratel-social-preview.png` is the prepared social
preview source. A repository owner must upload it through GitHub's repository
social-preview setting; that setting is intentionally not changed by CI or the
release workflow.
