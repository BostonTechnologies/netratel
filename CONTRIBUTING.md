# Contributing to NetRatel

Open an issue before substantial changes. Keep pull requests focused, include
tests, and never add customer data, credentials, infrastructure identifiers, or
private-environment screenshots.

Run the Release build and relevant tests before opening a pull request. Public
configuration examples must use reserved example values; secrets are supplied
only at deployment time.

Read [repository instructions](AGENTS.md) before editing. Documentation starts at [docs/README.md](docs/README.md); update the canonical guide in its category and run `tools/ci/validate-layout.sh` after moving files or changing local links. Current setup instructions and historical release evidence must remain distinct.
